Guidance for Claude Code when working with this repository.

## Prerequisites

**R version must match renv.lock.** This project requires R 4.5.2. Before running any R commands, ensure the correct version is active:

```bash
R --version | head -1
rig default 4.5.2  # If using rig
```

On Windows, if rig doesn't update the shell PATH, use the full path:
```bash
"/c/Program Files/R/R-4.5.2/bin/x64/R.exe" -e "devtools::test('src')"
```

## Project Overview

R package (`r.package`) deployed as an AWS Lambda function via Docker. Calculates average lift from S3-sourced CSV data.

## S7 Classes and Generics

| Class | Purpose |
|-------|---------|
| `S3DataSource` | Reads `S3_BUCKET_NAME`/`S3_DATA_KEY` env vars, holds S3 client |
| `LiftAnalysis` | Main model; fetches data on construction, validates spend column |
| `LiftSimResults` | S3 class wrapping numeric vector for simulation output |

| Generic | Description |
|---------|-------------|
| `fetch_data(source)` | Downloads CSV from S3, returns data.frame |
| `fit(model, scaling_factor)` | Runs simulation, returns LiftSimResults |
| `average_lift(x, na.rm)` | Calculates mean of simulation results |

- ECR repository: `lift-model-{env}`

## CI/CD

Deployment is fully automated via GitHub Actions with reusable workflows:

### Reusable Workflows

| Workflow | Purpose |
|----------|---------|
| `test-package-r.yml` | Runs R CMD CHECK on the package |
| `test-build.yml` | Builds Docker image and verifies package loads |
| `test-deployment.yml` | Invokes Lambda and validates response |

### Main Workflows

| Workflow | Trigger | Pipeline |
|----------|---------|----------|
| `ci.yml` | PR/push to main | test-package-r -> test-build |
| `deploy-dev.yml` | CI success on main | deploy -> test-deployment |
| `deploy-prod.yml` | Manual dispatch | ci -> deploy-dev -> deploy-prod -> test-deployment |

CI runs R CMD CHECK and Docker smoke test. Deploy workflows build, push to ECR, and run `terraform apply`.

**Note:** `deploy-prod.yml` runs the full CI pipeline and deploys to dev before production, ensuring the same code is verified in dev first.

## Lambda Runtime

`runtime.R` initializes model at cold start:
```r
data_source <- S3DataSource()
model <- LiftAnalysis(data_source = data_source)
```

Handler: `calculate_lift(scaling_factor = 1.5)` returns `list(lift = <mean>)`.

### Environment Variables (set by Terraform)

| Variable | Value |
|----------|-------|
| `ENV` | Environment name |
| `S3_BUCKET_NAME` | S3 bucket ID |
| `S3_DATA_KEY` | `data.csv` |

### Invoke

```bash
aws lambda invoke --function-name calculate_lift_dev \
  --payload '{"scaling_factor": 2.0}' \
  --cli-binary-format raw-in-base64-out \
  response.json
```
